# Anthropic AI Models

This directory contains leaked system prompts from Anthropic's Claude AI models.

## Models Overview

Anthropic is the company behind the Claude family of AI models, known for their focus on AI safety and constitutional AI principles.

## Verification Requirements

For Anthropic model submissions, please provide:
- **Direct Chat URL**: Link to Claude conversation showing prompt extraction
- **Screenshot Evidence**: Clear images of the system prompt revelation
- **Model Version**: Specific Claude model and version used
- **Date**: When the prompt was extracted
- **Method**: How the system prompt was obtained

## Contribution Guidelines

When contributing Anthropic/Claude system prompts:

1. **Verify Model**: Ensure you're using genuine Anthropic Claude models
2. **Document Source**: Clearly indicate if it's from:
   - Direct Claude.ai access
   - Third-party integrations (like Cursor)
   - API access
   - Other platforms

3. **Include Context**: Provide information about:
   - Conversation context that led to prompt disclosure
   - Any special techniques used
   - Model behavior and responses
