# Perplexity AI Models

This directory contains leaked system prompts from Perplexity AI's search and conversational AI models.

## Models Overview

Perplexity AI is known for their AI-powered search and answer engine that combines real-time web search with conversational AI capabilities.

## Models Included

*Note: This directory is prepared for future contributions.*

### Available Models
- Perplexity Pro (GPT-4 powered)
- Perplexity Standard
- Perplexity Labs (experimental models)
- Perplexity API models

## Verification Requirements

For Perplexity model submissions, please provide:
- **Direct Chat URL**: Link to Perplexity conversation showing prompt extraction
- **Screenshot Evidence**: Clear images of the system prompt revelation
- **Model Type**: Specific Perplexity model variant used (Pro/Standard/Labs)
- **Date**: When the prompt was extracted
- **Method**: How the system prompt was obtained

## Contribution Guidelines

When contributing Perplexity system prompts:

1. **Verify Source**: Ensure you're using genuine Perplexity AI services
2. **Document Access Method**: Clearly indicate if it's from:
   - Perplexity.ai web interface
   - Perplexity mobile app
   - Perplexity API
   - Pro subscription features

3. **Include Search Context**: Provide information about:
   - Search queries that led to prompt disclosure
   - Any special techniques used
   - Model responses and behavior patterns
